# Interactive Dish - Palmer Clone

A clone coding project inspired by Palmer's high-quality dinnerware website, featuring premium UI/UX with smooth animations and interactive 3D elements.

## Tech Stack

### Framework
- **Next.js 16** - React framework with App Router
- **TypeScript** - Type-safe development

### Styling
- **Tailwind CSS** - Utility-first CSS framework

### Animation & Interaction
- **GSAP** - ScrollTrigger, Parallax effects
- **Framer Motion** - Component transitions
- **Lenis** - Smooth scrolling

### 3D Graphics
- **Three.js** - 3D rendering
- **React-three-fiber** - React renderer for Three.js
- **@react-three/drei** - Useful helpers for R3F

### State Management
- **Zustand** - Lightweight state management

## Project Structure

```
interactive-dish/
├── app/              # Next.js app directory
├── components/       # React components
├── lib/              # Utility functions
├── types/            # TypeScript type definitions
├── store/            # Zustand stores
└── public/           # Static assets
    └── assets/       # Images, videos, models
```

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)
